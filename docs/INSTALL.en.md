# Installation

1. Exit the previous Island app from its tray menu. Run the Windows Setup executable for your chosen version. Current source: v0.28.14; GitHub downloads depend on the actual release attachments.
2. Setup installs for the current Windows user and includes .NET and the music host. Administrator rights and a separate AI service are unnecessary.
3. Open Settings → AI assistant, paste your Gemini key and confirm your project's free-tier status. Saving takes effect immediately. Local quota checks do not call the model.
4. Open the assistant context menu → Search APIs and rotation. Enter your own Exa, Tavily and Firecrawl keys and order; configure Firecrawl’s monthly renewal day and time in Taiwan time.

There are no app-enforced daily/minute request or cumulative token quota caps. Provider API failures and reset information trigger fallback. Keys and usage records are preserved. Configure Groq and Cloudflare through Settings → AI Assistant → AI model fallback; see [setup instructions](AI-FALLBACK.md). Windows OCR reads image text locally; raw images are not uploaded. With AI configured, captionless pastes also use the recognized text and conversation context for normal AI responses. Exa and Tavily have no local quota caps. Any search API failure, including a timeout, rate limit, key or quota error, disables the affected provider until the 2nd of the next month at 00:05 Taiwan time. The next available provider takes over (Exa → Tavily → Firecrawl). The next search after that time retries the provider; another failure defers it until the following month's 2nd. User cancellation does not count as a failure. This local retry schedule does not guarantee the provider's credit renewal time. Tavily and Firecrawl have an official usage refresh button. Tavily balances are informational and are not checked before searches; Firecrawl has no local credit cap. Its official remaining credits determine availability; set the renewal day and time to match your account. After depletion, the next search at or after that time rechecks credits. If still empty, recheck after an hour. Shorter months use their last day. Manual official refresh can restore availability earlier when credits are present. All existing provider caps are removed automatically while keys and usage records are preserved. The settings page shows the failure reason and retry time; manual unlocking is unnecessary.

Existing keys, usage, chats, reminders and memories survive upgrades and uninstall. AI compatibility data remains under Windows Documents/ChatGPT/GeminiHub; this is a data folder, not a service. Personal UI data remains under %LocalAppData%/EndfieldChargePlus. Daily stores its own data independently. DPAPI encryption is tied to the Windows user.

Alt+A opens AI; Alt+M opens music. YouTube playlist mode requires Microsoft Edge WebView2 Runtime. Reminders require the app to be running. See [Usage](USAGE.en.md) and [Privacy](PRIVACY.md).
