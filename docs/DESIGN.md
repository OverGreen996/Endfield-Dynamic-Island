# 工業介面設計

| 用途 | 色彩 |
| --- | --- |
| 主畫布 | `#191D1D` |
| 標頭 | `#202729` |
| 面板 | `#323736` |
| 資訊與選取 | `#13C8EB` / `#8DE1ED` |
| 主要操作／使用者頭像 | `#E6E744` |
| 主要文字 | `#F0F1EA` |
| 次要文字 | `#B4BBB5` |

以 UI/UX Pro Max 的對比、資訊層級、間距與可讀性檢查為基礎，再沿用使用者指定的終末地工業視覺。避免常駐大型光暈、模糊特效與裝飾動畫。

AI 頭像維持青藍色，使用者頭像為黃色。HUD 指標使用 CPU / GPU / RAM / VRAM 英文標籤，數字與單位分層。膠囊黃色弧線沿實際邊緣繪製；可點區域不覆蓋透明角落。

主介面保留真正的 ENDFIELD INDUSTRIES 向量圖標、青藍資訊、黃色重要操作；不再使用巨大裝飾 CONTROL 方塊。公開頁首延續同一組配色，以向量繪製避免截圖洩漏桌面或聊天內容。
