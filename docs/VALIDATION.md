安裝、同版升級、解除安裝及重新安裝實測通過，捷徑與固定解除安裝識別正確。每步核對原始獨立 EXE、設定、對話、提醒與記憶的 SHA256；解除安裝保留個人資料。不啟用原本未啟用的開機自動執行，不修改 XNG 或 Gemini 服務。

原生 AI 隔離視窗實際以 Ctrl+V 貼入合成圖片、移除、重新貼入及 Enter 送出。預覽和移除不扣 Gemini 次數；「只聊天」成功送出扣一次，回答正確讀出合成圖片文字。圖片未寫入對話、記憶或 XNG；失敗時保留草稿。模型協助分類的真實測試包含寵物、工作、假設句與不確定偏好，分類不另發模型請求。

圖片辨識後接 XNG 的真實查詢成功走完辨識、搜尋與摘要，使用兩次 Gemini。這次 VS Code 故障查詢混入 Visual Studio 及一般部落格，未取得足以驗證的官方 VS Code 解法；不能把流程成功視為搜尋品質全面通過。搜尋算法仍由獨立 XNG 維護，本版未修改 XNG 核心。

公開檔案排除金鑰、token、對話、記憶、設定、私人清單與舊版資料。Windows Setup 附 .NET runtime、播放器與第三方授權；不配送便攜 ZIP。AI 功能需要另外部署相容的 Gemini Hub 0.2.0，安裝包不包含私人後端。Setup 尚未購買程式碼簽章。

像素／縮放測試使用合成資料與程式化視窗；不等於所有實體多螢幕、Windows DPI、通知來源或安裝器頁面皆已逐一手動驗收。首頁封面是品牌示意，非真實效能讀值。免費方案確認是本機綁定專案／金鑰／政策的聲明，並非 Google 即時帳務驗證；用量顯示本機紀錄，不宣稱能查全專案剩餘額度。

GitHub Actions 執行建置與五類隔離邏輯檢查。完整桌面測試可在 Windows 上執行 `scripts/Test.ps1`。
